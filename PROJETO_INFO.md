# Marcador Truco Acker — Informações do Projeto

## O que é este projeto

Aplicativo de marcador de Truco com voz (Francisca), dark/light mode, mão de 11, Escurinha, suporte a 2 ou 4 jogadores, histórico de partidas, timer, offline e gratuito/sem anúncios.

---

## Arquitetura (como funciona)

PWA no GitHub Pages que também alimenta o TWA (APK) no Google Play Store.
Atualizar o código aqui = app atualizado em todos os canais automaticamente (sem gerar novo APK).

## Como atualizar o app

1. Edite os arquivos nesta pasta (index.html, app.js, styles.css, etc.)
2. Rode ATUALIZAR_GITHUB.bat
3. Pronto — GitHub Pages publica em ~1 minuto

---

## Como atualizar metadados no Google Play

1. Acesse play.google.com/console (conta jacsonsax@gmail.com)
2. Marcador Truco Acker → Presença na Play Store → Página de detalhes do app
3. Faça as alterações → Visão geral da publicação → Enviar para revisão (até 7 dias)
